# ComfyUI Learning Lab

Repositório dedicado ao estudo e experimentação com **ComfyUI** e modelos de **Inteligência Artificial Generativa**, reunindo pequenos projetos e workflows independentes.

O objetivo é explorar, de forma **prática e didática**, diferentes técnicas de geração, edição, restauração e manipulação de imagens utilizando workflows do ComfyUI.

Cada projeto possui seu próprio workflow, exemplos e documentação, permitindo estudar as técnicas individualmente e compreender como diferentes modelos e nós podem ser combinados para resolver problemas específicos.
